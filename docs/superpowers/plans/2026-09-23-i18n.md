# i18n Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every string Konventix renders — page, toast, validation message, mail, PDF — comes out of one translation catalog, in the locale the operator, the brand and the person resolve to, with `en` as source and `de` shipped.

**Architecture:** Laravel JSON catalogs keyed by the English sentence, one `lang/de.json` per module plus one at the root, read by PHP through `__()` and by Vue through `laravel-vue-i18n`'s `$t()`/`trans()` from the same files. One middleware resolves operator → brand → user once per request and sets the app locale; Inertia shares the locale and its fallback chain; the Vue plugin loads the catalogs along that chain. Issued invoices and credit notes store the locale they were rendered in.

**Tech Stack:** Laravel 13 (`__()`, JSON loader, `loadJsonTranslationsFrom`), `laravel-vue-i18n` 2.9 (runtime only, no Vite plugin), Inertia 3 (`withApp` hook), Pest 5, vitest, ESLint (`vue/no-bare-strings-in-template`, eslint-plugin-vue 9.33).

**Spec:** `docs/decisions/0068-one-translation-catalog-per-module-english-source.md` (ADR-0068); GitLab #132 (acceptance criteria), #75 (button wording), ADR-0055 (`lang` attribute).

## Global Constraints

- Work happens on `develop` directly; no feature branch. Agents never commit — the orchestrator commits per wave.
- Every command runs inside Sail: `vendor/bin/sail artisan …`, `vendor/bin/sail composer …`, `vendor/bin/sail npm …`, `vendor/bin/sail npx …`.
- Locales in this run: `en` (default, fallback, source language) and `de` (du-form). `de_formal` is an overlay shipped later; the loader chain must already support it.
- Key = the English sentence, exactly as rendered. Placeholders are Laravel-style `:name`; plural strings use Laravel's `{1} one|[2,*] many` with `$tChoice`/`trans_choice`.
- Backend: `__('…')`. Vue templates: `$t('…')`. Vue/TS script: `trans('…')` for one-shot values, `wTrans('…')` when the value must react to a locale change (it never changes mid-page here, so `trans()` is the default). Never build a sentence by concatenation; use placeholders.
- No browser locale (`Accept-Language`) anywhere. Guests see the brand's locale.
- Never translate: log messages, exception messages for developers, config keys, enum values, route names, slugs, `data-testid`, `aria-hidden` glyphs, brand or product names, user content.
- Existing German source strings become English source strings; the German text moves into the module's `de.json`.
- `users.locale` `null` means "follow the brand". Contract events (`UserRegistered`, `UserProfileUpdated`) carry `?string $locale`.
- A module's catalog is `app-modules/<module>/lang/de.json`, sorted by key, 4-space indent, `ensure_ascii=false` (umlauts literal). The root catalog `lang/de.json` holds strings from `resources/js` and `app/`.
- Tests assert English text as before; English remains the rendered default in tests (`APP_LOCALE=en`, test operator locale `en`).
- Follow `.ai/rules/*.md`: semantic tokens only, `formatDateTime()` for timestamps, the unsaved-changes guard on stateful forms, module tests in `app-modules/<m>/tests`, `--parallel` suite, admin host in the URL for console tests.

## Review Focus

1. A signed-in person whose `users.locale` is `null` on a brand whose `brands.locale` is `null` must see the operator's locale — Task 1's `LocaleResolverTest` "falls through two nulls to the operator".
2. A user row with a stale unsupported value (`'fr'`) must not render keys or throw — Task 1's `LocaleResolverTest` "skips an unsupported user locale".
3. A queued mail for a user who never chose a locale must render in the brand's locale, not `config('app.locale')` — Task 8's `SendMessageLocaleTest`.
4. An invoice re-downloaded after the buyer switched to English must still be German — Task 9's `InvoiceLocaleFreezeTest`.
5. A page in `de` that shows brand content (a static page, a policy) must mark that container with the brand's `lang` when it differs from the page's — Task 10's `ContentLanguageAttributeTest`.

```php
<?php
// app-modules/platform/src/Locales/Locales.php
declare(strict_types=1);

namespace Konventix\Platform\Locales;

use Carbon\Carbon;
use Illuminate\Contracts\Foundation\Application;

/**
 * The locale vocabulary (ADR-0068 §8): which locales exist, which is a
 * variant overlaying which base, and the chain a lookup walks.
 */
final class Locales
{
    private const NATIVE_NAMES = [
        'en' => 'English',
        'de' => 'Deutsch',
        'de_formal' => 'Deutsch (Sie)',
    ];

    public function __construct(private readonly Application $app) {}

    /** @return list<string> */
    public function supported(): array
    {
        return array_values((array) $this->app['config']->get('app.locales', ['en']));
    }

    public function isSupported(?string $locale): bool
    {
        return $locale !== null && in_array($locale, $this->supported(), true);
    }

    public function base(string $locale): string
    {
        $variants = (array) $this->app['config']->get('app.locale_variants', []);

        return (string) ($variants[$locale] ?? $locale);
    }

    /**
     * The locale, every base beneath it, then the fallback — each once.
     *
     * @return list<string>
     */
    public function chain(string $locale): array
    {
        $chain = [$locale];

        while (($base = $this->base(end($chain))) !== end($chain)) {
            $chain[] = $base;
        }

        $chain[] = (string) $this->app['config']->get('app.fallback_locale', 'en');

        return array_values(array_unique($chain));
    }

    public function nativeName(string $locale): string
    {
        return self::NATIVE_NAMES[$locale] ?? $locale;
    }

    /**
     * Runs the callback under a locale and restores the previous one, so a
     * document rendered for one person never leaks into the next request
     * or job (ADR-0068 §5–6).
     */
    public function within(string $locale, callable $callback): mixed
    {
        $previous = $this->app->getLocale();
        $previousCarbon = Carbon::getLocale();

        $this->app->setLocale($locale);
        Carbon::setLocale($locale);

        try {
            return $callback();
        } finally {
            $this->app->setLocale($previous);
            Carbon::setLocale($previousCarbon);
        }
    }
}
```

```php
<?php
// app-modules/platform/src/Locales/LocaleResolver.php
declare(strict_types=1);

namespace Konventix\Platform\Locales;

use Illuminate\Http\Request;
use Konventix\Identity\Models\User;
use Konventix\Platform\Brands\BrandContext;
use Konventix\Platform\Models\Brand;
use Konventix\Platform\Models\Operator;
use Konventix\Platform\Operators\OperatorContext;

/**
 * ADR-0068 §4: operator → brand → user. A level that says nothing, or
 * names a locale this instance does not ship, is skipped.
 */
final class LocaleResolver
{
    public function __construct(private readonly Locales $locales) {}

    public function forOperator(?Operator $operator): string
    {
        return $this->firstSupported([$operator?->locale, (string) config('app.locale')]);
    }

    public function forBrand(?Brand $brand): string
    {
        if ($brand === null) {
            return $this->forOperator(null);
        }

        return $this->firstSupported([$brand->locale, $brand->operator?->locale, (string) config('app.locale')]);
    }

    public function forUser(?User $user, ?Brand $brand, ?Operator $operator = null): string
    {
        return $this->firstSupported([
            $user?->locale,
            $brand?->locale,
            ($operator ?? $brand?->operator)?->locale,
            (string) config('app.locale'),
        ]);
    }

    /**
     * The request's person, brand and operator — scoped bindings resolved at
     * call time, never captured (`.ai/rules/providers.md`).
     */
    public function forRequest(Request $request): string
    {
        $user = $request->user();

        return $this->forUser(
            $user instanceof User ? $user : null,
            app(BrandContext::class)->current(),
            app(OperatorContext::class)->current(),
        );
    }

    /**
     * For queued work that has ids, not models (ADR-0068 §5).
     */
    public function forUserId(string $userId, ?string $brandId): string
    {
        $user = User::query()->find($userId);
        $brand = $brandId === null ? null : Brand::query()->withoutGlobalScopes()->find($brandId);

        return $this->forUser($user, $brand);
    }

    /** @param list<string|null> $candidates */
    private function firstSupported(array $candidates): string
    {
        foreach ($candidates as $candidate) {
            if ($this->locales->isSupported($candidate)) {
                return (string) $candidate;
            }
        }

        return (string) config('app.fallback_locale', 'en');
    }
}
```

Bind both in `PlatformServiceProvider::registerBindings()` beside the other singletons: `$this->app->singleton(Locales::class); $this->app->singleton(LocaleResolver::class);`. (`Locales` takes the `Application`, which is a singleton — safe. `LocaleResolver` takes `Locales` — safe. Neither captures a scoped binding.)

```php
<?php
// app-modules/platform/src/Locales/VariantAwareLoader.php
declare(strict_types=1);

namespace Konventix\Platform\Locales;

use Illuminate\Contracts\Translation\Loader;

/**
 * Laravel knows one fallback locale. ADR-0068 §8 needs a chain: a
 * variant (`de_formal`) holds only the lines whose address differs and
 * reads its base (`de`) for the rest. This decorator merges the base
 * catalogs beneath the variant's for the JSON group; everything else
 * passes through untouched.
 */
final class VariantAwareLoader implements Loader
{
    public function __construct(
        private readonly Loader $inner,
        private readonly Locales $locales,
    ) {}

    public function inner(): Loader
    {
        return $this->inner;
    }

    public function load($locale, $group, $namespace = null): array
    {
        $lines = $this->inner->load($locale, $group, $namespace);

        if ($group !== '*' || $namespace !== '*') {
            return $lines;
        }

        $chain = $this->locales->chain((string) $locale);
        // Bases only: the fallback at the end is the translator's own job.
        $bases = array_slice($chain, 1, -1);

        foreach ($bases as $base) {
            $lines = array_merge($this->inner->load($base, '*', '*'), $lines);
        }

        return $lines;
    }

    public function addNamespace($namespace, $hint): void
    {
        $this->inner->addNamespace($namespace, $hint);
    }

    public function addJsonPath($path): void
    {
        $this->inner->addJsonPath($path);
    }

    public function namespaces(): array
    {
        return $this->inner->namespaces();
    }
}
```

```ts
// resources/js/lib/i18n.ts
import { i18nVue } from 'laravel-vue-i18n';
import type { App } from 'vue';

/**
 * ADR-0068: the catalogs PHP reads are the catalogs Vue reads. Every
 * `lang/<locale>.json` at the root and under `app-modules/<module>/lang/`
 * is one map at runtime; a variant locale (`de_formal`) overlays its base.
 *
 * The chain comes from the server (`localeChain`, e.g. `['de_formal',
 * 'de', 'en']`) so the variant table lives in `config/app.php` only.
 */
export type Catalog = Record<string, string>;

const SOURCE_LOCALE = 'en';

/**
 * Pure: pick every file whose basename is `<locale>.json` for each locale
 * in the chain, base first, root before modules, later files winning.
 */
export function catalogFor(chain: string[], files: Record<string, Catalog>): Catalog {
    const merged: Catalog = {};
    const locales = [...chain].filter((locale) => locale !== SOURCE_LOCALE).reverse();

    for (const locale of locales) {
        const paths = Object.keys(files)
            .filter((path) => path.endsWith(`/${locale}.json`))
            .sort((a, b) => Number(a.includes('/app-modules/')) - Number(b.includes('/app-modules/')) || a.localeCompare(b));

        for (const path of paths) {
            Object.assign(merged, files[path]);
        }
    }

    return merged;
}

type Loaded = { default: Catalog };

// SSR bundles both locales eagerly: `resolve` must not return a promise
// there (the render is synchronous once the page chunk is in). The client
// loads only the files of the requested locale.
const eagerFiles = import.meta.env.SSR
    ? (import.meta.glob(['/lang/*.json', '/app-modules/*/lang/*.json'], { eager: true }) as Record<string, Loaded>)
    : {};

const lazyFiles = import.meta.glob(['/lang/*.json', '/app-modules/*/lang/*.json']) as Record<string, () => Promise<Loaded>>;

function unwrap(loaded: Record<string, Loaded>): Record<string, Catalog> {
    return Object.fromEntries(Object.entries(loaded).map(([path, module]) => [path, module.default]));
}

async function loadFilesFor(chain: string[]): Promise<Record<string, Catalog>> {
    const wanted = Object.entries(lazyFiles).filter(([path]) => chain.some((locale) => path.endsWith(`/${locale}.json`)));
    const loaded = await Promise.all(wanted.map(async ([path, load]) => [path, (await load()).default] as const));

    return Object.fromEntries(loaded);
}

/**
 * Installed from `createInertiaApp`'s `withApp` hook, once per Vue app.
 * The plugin's shared I18n instance is module state under SSR, exactly
 * like `configureDateTime` in app.ts: it is set here, synchronously, with
 * nothing awaited between this and the render.
 */
export function installI18n(app: App, options: { chain: string[]; ssr: boolean }): void {
    const { chain, ssr } = options;
    const lang = chain[0] ?? SOURCE_LOCALE;

    app.use(i18nVue, {
        lang,
        fallbackLang: SOURCE_LOCALE,
        fallbackMissingTranslations: true,
        resolve: ssr
            ? () => catalogFor(chain, unwrap(eagerFiles))
            : async () => catalogFor(chain, await loadFilesFor(chain)),
    });
}
```

```ts

        installI18n(app, { chain: page.props.localeChain ?? ['en'], ssr });
    },
```

```php
<?php
// tests/Unit/TranslationCatalogTest.php
declare(strict_types=1);

use Symfony\Component\Finder\Finder;

/*
| ADR-0068 §9: a key the source uses must exist in every shipped catalog, a
| key no source uses must not linger, and one English sentence must not
| carry two Germans across modules. A grep is blunt; blunt is what keeps a
| sweep swept (see DateTimeRenderingTest).
*/

function catalogRoot(string $to = ''): string
{
    return rtrim(dirname(__DIR__, 2).'/'.$to, '/');
}

/** @return array<string, array<string, string>> path => catalog */
function catalogs(string $locale): array
{
    $files = (new Finder)->files()->in([catalogRoot('lang'), catalogRoot('app-modules')])->path('/^(.*\/)?lang\//')->name("{$locale}.json");
    $out = [];

    foreach ($files as $file) {
        $out[$file->getRelativePathname()] = json_decode($file->getContents(), true, 512, JSON_THROW_ON_ERROR);
    }

    return $out;
}

/** @return array<string, true> every literal key used in PHP, Vue and TS */
function usedKeys(): array
{
    $finder = (new Finder)->files()
        ->in([catalogRoot('app'), catalogRoot('app-modules'), catalogRoot('resources')])
        ->exclude(['node_modules', 'vendor', 'tests', 'wayfinder', 'actions', 'routes'])
        ->name(['*.php', '*.vue', '*.ts']);
    $keys = [];
    $pattern = '/(?<![\w$])(?:__|trans|wTrans|transChoice|wTransChoice|trans_choice|\$t|\$tChoice)\(\s*([\'"])((?:\\\\.|(?!\1).)*)\1/';

    foreach ($finder as $file) {
        if (preg_match_all($pattern, $file->getContents(), $m)) {
            foreach ($m[2] as $key) {
                $keys[stripcslashes($key)] = true;
            }
        }
    }

    return $keys;
}

it('has a german line for every key the source uses', function (): void {
    $known = array_merge(...array_values(catalogs('de')));
    $missing = array_diff_key(usedKeys(), $known);

    expect(array_keys($missing))->toBe([]);
});

it('keeps no german line the source no longer uses', function (): void {
    $stale = [];

    foreach (catalogs('de') as $path => $catalog) {
        foreach (array_diff_key($catalog, usedKeys()) as $key => $_) {
            $stale[] = "{$path}: {$key}";
        }
    }

    expect($stale)->toBe([]);
});

it('gives one english sentence one german across modules', function (): void {
    $seen = [];
    $conflicts = [];

    foreach (catalogs('de') as $path => $catalog) {
        foreach ($catalog as $key => $value) {
            if (isset($seen[$key]) && $seen[$key][1] !== $value) {
                $conflicts[] = "{$key}: {$seen[$key][0]} says '{$seen[$key][1]}', {$path} says '{$value}'";
            }

            $seen[$key] = [$path, $value];
        }
    }

    expect($conflicts)->toBe([]);
});

it('never ships an english value as a german line', function (): void {
    $untranslated = [];

    foreach (catalogs('de') as $path => $catalog) {
        foreach ($catalog as $key => $value) {
            if ($value === $key && preg_match('/[a-z]{3,}/i', $key) && ! preg_match('/^(OK|Name|Status|Ticket|Team|Event|Brand|E-Mail|Link|Login|Logout|Admin|Steam|Discord|Twitch|Instagram|PDF|QR|ID|URL|Sponsor|Sponsoring|Support|Community|Plus|Standard|Premium|Session|Fair|Hub|Wallet|Nickname|Tag|Tags)$/', $key)) {
                $untranslated[] = "{$path}: {$key}";
            }
        }
    }

    expect($untranslated)->toBe([]);
});
```
