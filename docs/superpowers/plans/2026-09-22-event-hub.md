# Live-Event Hub Implementation Plan (0.9.0, sub-project A)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An admitted participant (checked in at the entrance) sees, while the event runs, a topbar pill and a `/live` hub page filled with module cards; the operator composes the hub per event and may make it the home page for admitted users.

**Architecture:** Admission projects `admission_event_presence` from its own check-ins and emits three participant events; Platform projects those into `platform_hub_access`, resolves an `ActiveEventContext` per authenticated request from one cache read, and renders the hub from a `HubRegistry` modules fill; Event owns the per-event layout row and emits it as an event Platform projects. No module reads another module's tables (ADR-0004).

> **As built:** wherever this plan says *three* participant events (here, Tasks 2, 7, 8 and 14), there are **four** — `ParticipantAdmitted`, `ParticipantPresenceChanged`, `ParticipantHubAccessEnded` and `ParticipantAdmissionReplaced`, the last of them added by the survivor ruling during Task 7. The plan is kept as it was written; the shipped contract is in `app-modules/admission/SPEC.md` and the design spec §4.3.

**Tech Stack:** Laravel 12 modules (`app-modules/*`), Pest 3 on Postgres (`vendor/bin/sail artisan test`), spatie/laravel-data + typescript-transformer, Inertia v3 + Vue 3 + shadcn-vue, Wayfinder route helpers, Laravel Pennant module gates.

**Spec:** `docs/superpowers/specs/2026-09-22-event-hub-design.md` (D-HUB-01..07).

## Global Constraints

- `brand_id` is never mass-assigned: projections use `->forceFill(['brand_id' => …])`, and read outside a brand host with `Model::withoutBrandScope()->where('brand_id', …)`.

- `Event::fake([...])` always with explicit classes (never blanket).
- Listeners are registered explicitly in `registerListeners()` — discovery is off.
- UI copy in Vue is literal German for participant-facing surfaces (the hub, the pill, the operator's Live-Hub page), matching the spec's labels; existing English admin copy stays as it is.
- Commit after every task, directly on `develop`, message in the repo's style (a sentence, what the user gains, issue refs where they exist). Do not open GitLab issues for follow-ups; note them in the module `TODO.md`.
- Deviation from spec §5.1 recorded here: `ParticipantAdmitted` carries `eventName`, `eventSlug`, `dayLabel` and `admissionId`, so Platform needs no listener on Event's events; the spec is updated in Task 16.

<?php

declare(strict_types=1);

namespace Konventix\Admission\Presence;

use Carbon\CarbonImmutable;
use Konventix\Admission\Enums\ReentryPolicy;
use Konventix\Admission\Models\EntranceEventProfile;

/**
 * When a participant's hub access closes (D-HUB-01). Once-per-day events
 * close at the scanned day's `day_ends_at` — before noon meaning the night
 * after that day, from noon on meaning the same day — with 00:00 of the
 * following day as the default. Every other policy stays open until the
 * event concludes, which is a `null` end here and `EventConcluded`'s job.
 *
 * Dates are resolved in the event's own zone (ADR-0027) and the result is
 * handed back as a UTC instant so the sweep compares plain timestamps.
 */
final class PresenceWindow
{
    /**
     * @return array{ends_at: CarbonImmutable|null, day_label: string|null}
     */
    public function for(EntranceEventProfile $profile, ?string $timezone, CarbonImmutable $scannedAt): array
    {
        $zone = $timezone ?? 'UTC';
        $local = $scannedAt->setTimezone($zone);
        $day = $profile->dayCovering($local);

        if ($profile->reentry_policy !== ReentryPolicy::OncePerDay) {
            return ['ends_at' => null, 'day_label' => $day['label'] ?? null];
        }

        $date = CarbonImmutable::parse($day['date'] ?? $local->toDateString(), $zone);
        [$hour, $minute] = array_map(intval(...), explode(':', $day['day_ends_at'] ?? '00:00'));

        $end = $date->setTime($hour, $minute);

        if ($hour < 12) {
            $end = $end->addDay();
        }

        return ['ends_at' => $end->utc(), 'day_label' => $day['label'] ?? null];
    }
}
```

<?php

declare(strict_types=1);

namespace Konventix\Admission\Actions;

use Carbon\CarbonImmutable;
use Konventix\Admission\Enums\HubAccessEndReason;
use Konventix\Admission\Events\ParticipantAdmitted;
use Konventix\Admission\Events\ParticipantHubAccessEnded;
use Konventix\Admission\Events\ParticipantPresenceChanged;
use Konventix\Admission\Models\Admission;
use Konventix\Admission\Models\EntranceEventProfile;
use Konventix\Admission\Models\EventPresence;
use Konventix\Admission\Models\EventSummary;
use Konventix\Admission\Presence\PresenceWindow;

/**
 * Maintains `admission_event_presence` (design §4.2) and emits the three
 * participant events the rest of the platform reacts to. Takes scalars —
 * the listeners unpack the events — and escapes the brand scope by the
 * payload's own brand id, since it runs from queue workers with no
 * ambient brand (ADR-0010).
 */
final class ProjectEventPresence
{
    public function __construct(private readonly PresenceWindow $window) {}

    public function checkIn(string $brandId, string $eventId, string $admissionId, string $direction, CarbonImmutable $scannedAt): ?EventPresence
    {
        $admission = Admission::withoutBrandScope()->where('brand_id', $brandId)->find($admissionId);

        // A claim-link holder without an account has nothing to sign in to;
        // no row, no error (design §4.2).
        if ($admission === null || $admission->holder_user_id === null) {
            return null;
        }

        $presence = EventPresence::withoutBrandScope()
            ->where('brand_id', $brandId)
            ->where('event_id', $eventId)
            ->where('user_id', $admission->holder_user_id)
            ->first();

        if ($direction === 'out') {
            if ($presence === null || $presence->last_direction === 'out') {
                return $presence;
            }

            $presence->forceFill(['last_direction' => 'out', 'last_check_in_at' => $scannedAt])->save();
            event(new ParticipantPresenceChanged($presence->user_id, $eventId, $brandId, 'out', $scannedAt->toIso8601String()));

            return $presence;
        }

        $profile = EntranceEventProfile::withoutBrandScope()->where('brand_id', $brandId)->where('event_id', $eventId)->first();
        $summary = EventSummary::withoutBrandScope()->where('brand_id', $brandId)->where('event_id', $eventId)->first();
        $window = $profile === null
            ? ['ends_at' => null, 'day_label' => null]
            : $this->window->for($profile, $summary?->timezone, $scannedAt);

        $hadAccess = $presence?->hub_access === true;
        $wasIn = $presence?->last_direction === 'in';

        $presence ??= (new EventPresence)->forceFill([
            'brand_id' => $brandId,
            'event_id' => $eventId,
            'user_id' => $admission->holder_user_id,
            'first_admitted_at' => $scannedAt,
        ]);

        $presence->forceFill([
            'admission_id' => $admissionId,
            'last_check_in_at' => $scannedAt,
            'last_direction' => 'in',
            'window_ends_at' => $window['ends_at'],
            'hub_access' => true,
            'access_ended_reason' => null,
            'day_label' => $window['day_label'],
        ])->save();

        if (! $hadAccess) {
            event(new ParticipantAdmitted(
                userId: $presence->user_id,
                eventId: $eventId,
                brandId: $brandId,
                admissionId: $admissionId,
                admittedAt: $scannedAt->toIso8601String(),
                windowEndsAt: $window['ends_at']?->toIso8601String(),
                dayLabel: $window['day_label'],
                eventName: $summary?->name,
                eventSlug: $summary?->slug,
            ));
        }

        if (! $wasIn) {
            event(new ParticipantPresenceChanged($presence->user_id, $eventId, $brandId, 'in', $scannedAt->toIso8601String()));
        }

        return $presence;
    }

    public function endForEvent(string $brandId, string $eventId, HubAccessEndReason $reason, CarbonImmutable $at): int
    {
        return $this->end(
            EventPresence::withoutBrandScope()->where('brand_id', $brandId)->where('event_id', $eventId),
            $reason,
            $at,
        );
    }

    public function endForAdmission(string $brandId, string $admissionId, HubAccessEndReason $reason, CarbonImmutable $at): int
    {
        return $this->end(
            EventPresence::withoutBrandScope()->where('brand_id', $brandId)->where('admission_id', $admissionId),
            $reason,
            $at,
        );
    }

    public function closeExpiredWindows(CarbonImmutable $now): int
    {
        return $this->end(
            EventPresence::withoutBrandScope()->whereNotNull('window_ends_at')->where('window_ends_at', '<=', $now),
            HubAccessEndReason::DayEnded,
            $now,
        );
    }

    /**
     * @param  \Illuminate\Database\Eloquent\Builder<EventPresence>  $query
     */
    private function end($query, HubAccessEndReason $reason, CarbonImmutable $at): int
    {
        $ended = 0;

        $query->where('hub_access', true)->orderBy('id')->chunkById(200, function ($rows) use ($reason, $at, &$ended): void {
            foreach ($rows as $presence) {
                $presence->forceFill(['hub_access' => false, 'access_ended_reason' => $reason])->save();
                event(new ParticipantHubAccessEnded($presence->user_id, $presence->event_id, $presence->brand_id, $reason->value, $at->toIso8601String()));
                $ended++;
            }
        });

        return $ended;
    }
}

<?php

declare(strict_types=1);

namespace Konventix\Platform\Hub;

use Illuminate\Support\Collection;
use Illuminate\Support\Facades\Cache;
use Konventix\Platform\Brands\BrandContext;
use Konventix\Platform\Data\ActiveEventData;
use Konventix\Platform\Models\HubAccess;

/**
 * Which running event the signed-in user is admitted to on this brand
 * (design §5.1). Scoped per request; one cache read for a member, none at
 * all for a guest — the guest home page must stay as cheap as it is.
 */
final class ActiveEventContext
{
    public const TTL_SECONDS = 600;

    /** @var Collection<int, ActiveEventData>|null */
    private ?Collection $resolved = null;

    public function __construct(private readonly BrandContext $brands) {}

    public function current(): ?ActiveEventData
    {
        return $this->all()->first();
    }

    /** @return Collection<int, ActiveEventData> */
    public function all(): Collection
    {
        if ($this->resolved !== null) {
            return $this->resolved;
        }

        $brand = $this->brands->current();
        $userId = auth()->id();

        if ($brand === null || $userId === null) {
            return $this->resolved = Collection::make();
        }

        $rows = Cache::remember(self::key($brand->id, (string) $userId), self::TTL_SECONDS, fn (): array => HubAccess::withoutBrandScope()
            ->where('brand_id', $brand->id)
            ->where('user_id', (string) $userId)
            ->orderByDesc('admitted_at')
            ->get()
            ->map(fn (HubAccess $row): array => $row->toActiveEvent()->toArray())
            ->all());

        return $this->resolved = Collection::make($rows)->map(fn (array $row): ActiveEventData => ActiveEventData::from($row));
    }

    public static function key(string $brandId, string $userId): string
    {
        return "hub-access:{$brandId}:{$userId}";
    }

    public static function forget(string $brandId, string $userId): void
    {
        Cache::forget(self::key($brandId, $userId));
    }
}

 * Payload closures are never run here — `HubPage` runs them for the cards
 * the operator's layout keeps, so a hidden card costs nothing.
 */
final class HubRegistry
{
    /** @var list<HubCard|HubLink> */
    private array $items = [];

    public function __construct(private readonly ModuleGate $gate) {}

    public function add(HubCard|HubLink ...$items): void
    {
        foreach ($items as $item) {
            $this->items[] = $item;
        }
    }

    /** @return Collection<int, HubCard> */
    public function visibleCards(Authenticatable $user): Collection
    {
        /** @var Collection<int, HubCard> */
        return $this->visible($user)->filter(fn ($item): bool => $item instanceof HubCard)->values();
    }

    /** @return Collection<int, HubLink> */
    public function visibleLinks(Authenticatable $user): Collection
    {
        /** @var Collection<int, HubLink> */
        return $this->visible($user)->filter(fn ($item): bool => $item instanceof HubLink)->values();
    }

    /** @return Collection<int, HubCard|HubLink> */
    public function all(): Collection
    {
        return Collection::make($this->items);
    }

    /** @return Collection<int, HubCard|HubLink> */
    private function visible(Authenticatable $user): Collection
    {
        return Collection::make($this->items)
            ->filter(fn (HubCard|HubLink $item): bool => $this->gate->isActive($item->module))
            ->filter(fn (HubCard|HubLink $item): bool => $item->permission === null || $user->can($item->permission))
            ->sortBy([
                fn ($a, $b): int => $a->order <=> $b->order,
                fn ($a, $b): int => strcmp($a->label, $b->label),
            ])
            ->values();
    }
}
```

public function render(Request $request): Response
{
    $event = $this->context->current() ?? abort(404);
    $user = $request->user() ?? abort(403);
    $layout = $this->layouts->for($event->eventId);

    $cards = $this->registry->visibleCards($user)->keyBy('key');

    $orderedKeys = $this->orderedKeys($layout['cards'], [...$cards->keys()->all(), ...$links->keys()->all()]);

    $cardData = [];
    $linkData = [];

    foreach ($orderedKeys as $key) {
        if ($cards->has($key)) {
            $card = $cards[$key];
            $cardData[] = new HubCardData($card->key, $card->label, $card->component, ($card->payload)($event, $user));
        } elseif ($links->has($key)) {
            $link = $links[$key];
            $linkData[] = new HubLinkData($link->key, $link->label, $link->url === null ? null : ($link->url)($event, $user), $link->component, $link->icon);
        }
    }

    app(Metrics::class)->increment('platform_hub_views_total', ['brand' => BrandSlugs::of(app(BrandContext::class)->current()->id)]);

    return Inertia::render('platform/live/Hub', [

/**
 * Layout order first (visible only, unknown keys dropped), then everything
 * registered but not yet in the layout, in registry order (design §6).
 *
 * @param  list<array{key: string, visible: bool}>  $layout
 * @param  list<string>  $registered
 * @return list<string>
 */
private function orderedKeys(array $layout, array $registered): array
{
    $listed = array_column($layout, 'key');
    $ordered = [];

    foreach ($layout as $entry) {
        if ($entry['visible'] && in_array($entry['key'], $registered, true)) {
            $ordered[] = $entry['key'];
        }
    }

    foreach ($registered as $key) {
        if (! in_array($key, $listed, true)) {
            $ordered[] = $key;
        }
    }

    return $ordered;
}

```php
<?php

declare(strict_types=1);

/**
 * A hub card belongs to its module (design §8): its Vue component may
 * import the host's shared UI and its own module's generated helpers, but
 * never another module's — otherwise a brand with that module off ships a
 * card that reaches into nothing.
 */
it('keeps hub components inside their own module', function (): void {
    $violations = [];

    foreach (glob(base_path('app-modules/*/resources/js/components/hub/*.vue')) ?: [] as $file) {
        preg_match('#app-modules/([^/]+)/#', $file, $m);
        $module = $m[1];
        $source = (string) file_get_contents($file);

        preg_match_all("#from\s+'([^']+)'#", $source, $imports);

        foreach ($imports[1] as $import) {
            $foreign = preg_match('#^@/(actions|routes)/([A-Za-z]+)#', $import, $r) === 1
                && strtolower($r[2]) !== str_replace('-', '', $module)
                && $r[2] !== 'Konventix';   // @/actions/Konventix/<Module>/…
            $foreignAction = preg_match('#^@/actions/Konventix/([A-Za-z]+)/#', $import, $a) === 1
                && strtolower($a[1]) !== str_replace('-', '', $module);
            $crossModule = str_contains($import, '/app-modules/') && ! str_contains($import, "/app-modules/{$module}/");

            if ($foreign || $foreignAction || $crossModule) {
                $violations[] = "{$file}: {$import}";
            }
        }
    }

    expect($violations)->toBe([]);
});
```

Sanity-check the regexes against the four components from Task 15 — `@/routes/admission` is fine for Admission, `@/actions/Konventix/Admission/...` is fine for Admission, `@/components/ui/card` is always fine.
